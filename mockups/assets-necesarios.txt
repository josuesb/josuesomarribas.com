NOTAS DE PRODUCCIÓN

- No rasterizar navegación, titulares, párrafos, CTAs, inputs, tablas ni bloques de código salvo cuando formen parte inseparable de una ilustración editorial.
- Mantener un mismo margen transparente alrededor de cada capa de una composición para que todas compartan origen y puedan superponerse sin reajustes.
- Exportar las composiciones hero también como imagen completa de referencia, además de sus capas animables.
- Los assets 01–11 deben funcionar como biblioteca compartida para evitar duplicados entre páginas.
- Para móvil, usar las mismas capas y recomponerlas; evitar generar una sola imagen horizontal que obligue a reducir demasiado el gráfico.
